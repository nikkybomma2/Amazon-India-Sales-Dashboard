# Amazon India Sales Dashboard
## Project Overview
The Amazon India Sales Dashboard is a Data Analytics project developed using Microsoft Excel to analyze sales, profit, products, orders, returns, cancellations, and fulfillment performance.
The goal is to present key business metrics in an interactive dashboard that helps stakeholders understand business performance and make data-driven decisions.
## Business Objectives
- Monitor overall sales and profit performance.
- Analyze monthly sales trends.
- Identify high-performing product categories and products.
- Track order status, returns, and cancellations.
- Compare sales and profit across fulfillment methods.
- Analyze state-wise sales and order performance.
## Tools Used
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Excel formulas
- Slicers and interactive filters
- KPI cards and data visualization
## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Total Units Sold
- Profit Margin %
- Return Rate %
- Cancellation Rate %
## Dashboard Features
- Order Status Analysis
- Month-wise Sales Trend
- Category-wise Total Profit
- State-wise Orders
- Category-wise Returns and Cancellations
- Top 5 Products Analysis
- State-wise Sales and Profit
- Sales by Fulfillment Method
- Interactive slicers for filtering data
## Key Business Questions
1. How is the business performing overall?
2. Which products and categories contribute to business performance?
3. What proportion of orders are returned or cancelled?
4. Which states generate the most orders?
5. How do fulfillment methods contribute to sales and profit?
